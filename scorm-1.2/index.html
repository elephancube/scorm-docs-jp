SCORM 1.2 仕様書 日本語訳 Sharable Content Object Reference Model — Version 1.2

ADL Initiative が 2001 年に発行した SCORM 1.2 の仕様書 4 冊を、LMS 開発者および SCORM コンテンツ作成者向けに日本語訳したものです（非公式）。

収録ドキュメント

  • BOOK 1

    The SCORM Overview scorm_overview_ja.html

    SCORM 全体像。Asset / SCO / Content Aggregation の概念導入、ADL の背景、LMS モデル。
  • BOOK 2

    Content Aggregation Model scorm_cam_ja.html

    コンテンツ・モデル、メタデータ (IEEE LOM)、コンテンツ・パッケージング (IMS)。
  • BOOK 3

    Run-Time Environment scorm_rte_ja.html

    Launch、API（8 関数）、Data Model、エラーコード。実装の中核。
  • BOOK 4

    The SCORM Addendums scorm_addendums_ja.html

    17 件のエラータ (2002 年 1 月)。CAM / RTE の修正箇所を FROM/TO 形式で記載。

推奨の読み順: Overview → CAM → RTE → Addendums。CAM / RTE 内には、対応する Addendums 項目への相互参照リンクが埋め込まれており、修正箇所から該当章へ直接ジャンプできます。

翻訳方針（要旨）

  • API 関数名 (LMSInitialize("") 等)、データモデル要素 (cmi.core.lesson_status 等)、エラーコード、データ型、語彙値は英語のまま <code> でマークアップ。
  • 標準的な英語形がある専門用語 (API / SCO / LMS 等) は安易にカタカナ化せず、初出時にフルスペルを併記。
  • 文体は「〜である」「〜する」調。原典のセクション番号・階層をそのまま維持。
  • 図版は SVG で再描画し、ラベルを日本語化（API 名・要素名は英語のまま）。
  • 詳細は README を参照。
